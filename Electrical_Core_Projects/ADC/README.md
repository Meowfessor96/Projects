# 5-bit SAR ADC using Arduino and LEDs

This project demonstrates a hardware-based 5-bit Successive Approximation Register (SAR) ADC built on a breadboard and visualized using 5 LEDs to represent binary outputs. An Arduino is used as part of the setup for voltage reference and/or control.

## 🧠 Concept

A Successive Approximation Register ADC converts analog voltage into a digital binary value by performing a bit-by-bit comparison, starting from the Most Significant Bit (MSB) to the Least Significant Bit (LSB). Each bit decision is made by comparing the input voltage with a reference generated by a DAC.

In this project, the **5-bit digital output is shown using 5 LEDs**, where:
- Each **LED represents one bit**
- An **ON LED = 1**, **OFF LED = 0**
- The LEDs light up from MSB (left) to LSB (right)

---

## ⚙️ Setup Overview

- ⚡ Input voltage is supplied via a resistor ladder or voltage divider.
- 🟦 An **Arduino** provides control and/or voltage reference for the DAC.
- 🔘 5 LEDs display the resulting 5-bit binary output.
- ⛓️ Comparisons are made internally (likely via logic and DAC feedback) to determine each bit.
- All components are placed on a breadboard.

**Note:** No microcontroller computation is used for conversion — the ADC logic is handled through hardware wiring and iterative comparisons.

## 🔢 LED Output and Voltage Mapping

The following binary outputs were observed in the demonstration video for different input voltages:

| Voltage Input (V) | 5-bit Binary Output | LED Display (MSB → LSB) |
|-------------------|---------------------|--------------------------|
| 2.0               | `11111`             | 🔴 🔴 🔴 🔴 🔴            |
| 1.6               | `11000`             | 🔴 🔴 ⚫ ⚫ ⚫            |
| 1.4               | `10110`             | 🔴 ⚫ 🔴 🔴 ⚫            |
| 1.2               | `10011`             | 🔴 ⚫ ⚫ 🔴 🔴            |

(🔴 = LED ON = Bit 1, ⚫ = LED OFF = Bit 0)

---

## 🎯 Final Output

- The LEDs act as a **binary indicator of analog voltage level**.
- As voltage increases, more significant bits turn ON.
- A voltage close to the full range (~2.0V) results in a full `11111` output.
- Lower voltages produce outputs with fewer bits set to 1.

## 🧪 Applications

This setup demonstrates the **core principle of ADCs** using minimal hardware:
- Useful for understanding digital conversion fundamentals
- Ideal for learning embedded hardware interfacing and signal mapping
- Can be extended to higher resolution (6-bit, 8-bit, etc.) or connected to microcontrollers for digital logging
